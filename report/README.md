# NexRag B.Tech Project Report

This folder contains a chapter-wise final year project report draft for the `NexRag` repository.

File order:

1. `00_front_matter.md`
2. `01_introduction.md`
3. `02_literature_review.md`
4. `03_proposed_system.md`
5. `04_results_and_discussion.md`
6. `05_conclusion_and_future_scope.md`
7. `06_references.md`

Formatting assumptions used while drafting:

- Body font: Times New Roman, 12 pt
- Line spacing: 1.5
- Preliminary pages: Roman numbering
- Chapter pages: Arabic numbering starting from Chapter 1
- Chapter titles: uppercase
- Figure captions below figures as `Figure X.X`
- Table titles above tables as `Table X.X`
- Equation numbers shown inline as `(X.X)`

Placeholders intentionally left for manual completion:

- Student name
- Register number
- Guide name
- Head of Department name
- Academic year / month of submission
- Final pagination after export to Word or PDF

The content is grounded in the current repository state, including:

- FastAPI backend
- React + Vite frontend
- FAISS, BM25, and cross-encoder retrieval
- Apache Jena Fuseki knowledge graph integration
- Ollama-based local generation
- Repository verification evidence collected on 2026-04-03
